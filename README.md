# 🧠 Brain Tumour Classification using Machine Learning & Custom CNN

**Design and Development of an Effective Classifier for Medical Images based on Custom CNN**

An end-to-end system for automated brain tumour detection and classification from MRI scans, combining classical machine learning, fine-tuned deep learning architectures, soft-voting ensembles, and an explainable-AI (LLM) layer — all implemented in MATLAB.

## 📌 Overview

Early detection of brain tumours is critical for effective treatment, but manual MRI examination is time-consuming and error-prone. This project builds a complete pipeline — from image preprocessing to explainable predictions — that:

- Performs **binary classification** (Tumour / No Tumour)
- Performs **multiclass classification** (Glioma / Meningioma / Pituitary tumour)
- Compares **classical ML** (SVM, KNN, Naïve Bayes) against **deep learning** (fine-tuned ResNet18, MobileNetV2, EfficientNet-B0, Custom MobileNet)
- Uses **Soft Voting Ensembles** to fuse predictions from multiple CNNs
- Integrates a **local LLM (Ollama – Phi-3)** to generate human-readable medical explanations for each prediction, delivered via a MATLAB App

> 📄 Presented at the **2nd International Conference on Advanced Technologies in Electronics, Communications and Signal Processing (ICATECS-2026)**, Springer.

## ⚠️ Before you run: things to fix

This code was assembled from separate working sessions, so a few filenames don't line up across scripts. Fix these before running end-to-end:

1. **ResNet18 binary model filename mismatch**
   `train_custom_cnn_resnet18_binary.m` saves `resnet18BrainTumor.mat`, but `test_custom_cnn_resnet18_binary.m` loads `bestModel_resnet18_final.mat`. Either rename the saved file or update `modelPath` in the test script.

2. **Custom MobileNet multiclass filename mismatch**
   `train_custom_mobilenet_multiclass.m` saves `FINAL_CustomMobileNetV2.mat`, but `test_custom_mobilenet_multiclass.m` and `hybrid_soft_voting_multiclass.m` both load `CustomMobileNet_Singlestage_70_15_15.mat` / `CustomMobileNet_SingleStage_70_15_15.mat` (note the casing difference between these two as well). Pick one filename and use it consistently everywhere.

3. **Model filename mismatches** (ResNet18 binary, Custom MobileNet multiclass)
   `train_custom_cnn_resnet18_binary.m` saves `resnet18BrainTumor.mat`, but `test_custom_cnn_resnet18_binary.m` loads `bestModel_resnet18_final.mat`. Similarly, `train_custom_mobilenet_multiclass.m` saves `FINAL_CustomMobileNetV2.mat`, but `test_custom_mobilenet_multiclass.m` and `hybrid_soft_voting_multiclass.m` load `CustomMobileNet_Singlestage_70_15_15.mat` / `CustomMobileNet_SingleStage_70_15_15.mat` (note the casing difference between these two as well). Pick one filename per model and use it consistently everywhere.

4. **`getss_llm_local.m` calls `fallback_explanation(label, confidence)`** on error, but that function wasn't included. Add a small `fallback_explanation.m` (e.g. returning a generic templated string) to `app/` before using the GUI.

5. **Hard-coded local paths** — every script has `datasetRoot` / model paths pointing at specific machines (e.g. `C:\BRAIN TUMOR PROJECT`, `E:\BRAIN TUMOR PROJECT`, `C:\Users\SAMPATH REDDY\...`). Update these to your own local paths before running.

6. **Two small case-sensitivity mismatches in dataset folder names** — see the [Dataset](#-dataset) section below (`Training`/`Testing` vs. `training`/`testing`, and `brain_training` vs `Brain_training`). Harmless on Windows, breaks on macOS/Linux.

7. **`soft_voting_binary.m` uses a different data split than the other binary scripts** — it loads all images recursively from `BRAIN TUMOR PROJECT` (ignoring the existing `Training`/`Testing` split) and creates its own stratified 70/24/6 (train/val/test) split at runtime. The other binary scripts use the pre-existing `Training`/`Testing` folders directly. This means test-set images may not be identical across scripts — keep this in mind when comparing results directly.

## 🧪 Methodology

### 1. Image Preprocessing
- Grayscale conversion & Gaussian noise removal
- Histogram equalization (contrast enhancement)
- K-Means segmentation (tumour region isolation)
- Feature extraction — PCA (dimensionality reduction) and HOG (shape/edge features, multiclass task)
- Z-score normalization
- Data augmentation: rotation, flipping, scaling, translation

![ML Classifiers Block Diagram](docs/figures/ml_classifiers_block_diagram.jpg)
![Multiclass ML Block Diagram](docs/figures/multiclass_ml_block_diagram.jpg)

### 2. Classical Machine Learning
- **SVM** — RBF kernel (binary: `fitcsvm`; multiclass: `fitcecoc` one-vs-one)
- **KNN** — instance-based (binary: k=5; multiclass: weighted, k=7)
- **Naïve Bayes** — probabilistic baseline (multiclass: kernel distribution)

![ML Classifiers Implementation Pipeline](docs/figures/ml_classifiers_pipeline.jpg)

### 3. Deep Learning

| Model | Architecture | Pipeline |
|---|---|---|
| Custom CNN (binary) | ![ResNet18 Architecture](docs/figures/custom_cnn_resnet18_architecture.jpg) | ![ResNet18 Pipeline](docs/figures/custom_cnn_resnet18_pipeline.jpg) |
| MobileNetV2 (multiclass) | ![MobileNetV2 Architecture](docs/figures/mobilenetv2_architecture.jpg) | ![MobileNetV2 Pipeline](docs/figures/mobilenetv2_pipeline.jpg) |
| Custom EfficientNet-B0 (multiclass) | ![EfficientNet-B0 Architecture](docs/figures/efficientnet_b0_architecture.jpg) | ![EfficientNet-B0 Pipeline](docs/figures/efficientnet_b0_pipeline.jpg) |
| Custom MobileNet (multiclass) | ![Custom MobileNetV2 Architecture](docs/figures/custom_mobilenetv2_architecture.jpg) | ![Custom MobileNet Pipeline](docs/figures/custom_mobilenet_pipeline.jpg) |

- **Custom CNN** — fine-tuned ResNet18 (binary classification)
- **MobileNetV2** — lightweight, transfer-learned (multiclass)
- **Custom EfficientNet-B0** — compound-scaled backbone (multiclass)
- **Custom MobileNet** — MobileNetV2 + dropout regularization + heavier augmentation (multiclass)

### 4. Ensemble Learning

![Soft Voting Block Diagram](docs/figures/soft_voting_block_diagram.jpg)

- **Soft Voting** across 5 CNNs (MobileNetV2, ResNet18, ResNet50, DenseNet201, EfficientNet-B0) for binary classification — `binary_classification/ensemble/soft_voting_binary.m`. Also reports Majority Vote and Test-Time Augmentation (TTA) variants alongside the primary Average Fusion (soft voting) result.
- **Confidence-weighted hybrid voting** (EfficientNet-B0 + Custom MobileNet) for multiclass classification, implemented in `hybrid_soft_voting_multiclass.m`

### 5. Explainable AI

![GUI + LLM Architecture](docs/figures/gui_llm_architecture.jpg)

- Predicted tumour class passed to a locally-hosted **Phi-3 (Ollama)** LLM via API
- Generates plain-language explanations: description, likely causes, symptoms, precautions
- Delivered through a MATLAB App Designer GUI (`app/app1.m`)

## 📊 Dataset

**Source:** [Brain Tumor Classification (MRI) — Sartaj Bhuvaji (Kaggle)](https://www.kaggle.com/datasets/sartajbhuvaji/brain-tumor-classification-mri)

The original Kaggle dataset ships with 4 classes (`glioma_tumor`, `meningioma_tumor`, `no_tumor`, `pituitary_tumor`), each already split into `Training/`/`Testing/` folders. **We regrouped these into two task-specific datasets** to match the binary and multiclass objectives of this project:

**1. `BRAIN TUMOR PROJECT/` — Binary Classification (Tumour vs. No Tumour)**

`no_tumor` kept as-is; `glioma_tumor` + `meningioma_tumor` + `pituitary_tumor` merged into a single `tumor` class.

| Class | Training | Testing | Total |
|---|---|---|---|
| No Tumour | 395 | 105 | 500 |
| Tumour | 2,475 | 289 | 2,764 |
| **Total** | **2,870** | **394** | **3,264** |

**2. `BRAINCLASSIFICATION/` — Multiclass Classification (Glioma / Meningioma / Pituitary)**

`no_tumor` excluded; the three tumour classes kept separate.

| Class | Training | Testing | Total |
|---|---|---|---|
| Glioma | 826 | 100 | 926 |
| Meningioma | 822 | 115 | 937 |
| Pituitary | 827 | 74 | 901 |
| **Total** | **2,475** | **289** | **2,764** |

> **Note:** Datasets are not included in this repository due to size (see `.gitignore`). Download the source from the Kaggle link above and regroup it into the two structures above, or use your own copies of these folders — see the folder-mapping table below for exactly where each script expects them.

**How each script's `datasetRoot` maps to these folders:**

| Script(s) | Expects | Folder to point at |
|---|---|---|
| `binary_classification/classical_ml/*`, `binary_classification/deep_learning/*` | `<datasetRoot>/training`, `<datasetRoot>/testing` | `BRAIN TUMOR PROJECT/` |
| `multiclass_classification/classical_ml/*` | `<datasetRoot>/Brain_training`, `<datasetRoot>/Brain_testing` | `BRAINCLASSIFICATION/` |
| `multiclass_classification/deep_learning/*` (MobileNetV2, Custom MobileNet, EfficientNet-B0) | `<datasetRoot>` with class subfolders (recursed via `imageDatastore(..., 'IncludeSubfolders', true)`, then re-split 70/15/15 with `splitEachLabel`) | `BRAINCLASSIFICATION/` |

⚠️ **Two small case-sensitivity issues to watch for** (harmless on Windows, but will break on macOS/Linux):
- The binary scripts look for lowercase `training`/`testing`, but the actual folders are capitalized `Training`/`Testing`.
- The multiclass classical-ML scripts look for `Brain_training` (capital B), but the actual folder is `brain_training` (lowercase b) — inconsistent with `Brain_testing`, which does match.

Either rename the folders to match exactly, or update the `datasetRoot`/`fullfile(...)` lines in the scripts to use the correct casing.

## 🚀 Usage

**Binary classification**
```matlab
% Classical ML (SVM / KNN / Naive Bayes) — trains and tests in one run
run('binary_classification/classical_ml/train_test_svm_knn_nb_binary.m');

% Deep learning (fine-tuned ResNet18) — trains (or loads if model exists) and tests
run('binary_classification/deep_learning/train_custom_cnn_resnet18_binary.m');

% 5-model Soft Voting Ensemble (MobileNetV2, ResNet18, ResNet50, DenseNet201, EfficientNet-B0)
run('binary_classification/ensemble/soft_voting_binary.m');
```

**Multiclass classification**
```matlab
% Classical ML
run('multiclass_classification/classical_ml/train_svm_knn_nb_multiclass.m');
run('multiclass_classification/classical_ml/test_svm_knn_nb_multiclass.m');

% Deep learning — pick one, train then test
run('multiclass_classification/deep_learning/train_custom_efficientnet_b0_multiclass.m');
run('multiclass_classification/deep_learning/test_custom_efficientnet_b0_multiclass.m');

run('multiclass_classification/deep_learning/train_custom_mobilenet_multiclass.m');
run('multiclass_classification/deep_learning/test_custom_mobilenet_multiclass.m');

% Ensemble (requires both EfficientNet-B0 and Custom MobileNet models saved)
run('multiclass_classification/ensemble/hybrid_soft_voting_multiclass.m');
```

**Explainable-AI GUI**
```matlab
% Requires: trained Custom MobileNet model + Ollama running locally
app = app1;
```
